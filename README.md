# RSA 学習メモ

RSA暗号の仕組みを理解するために、C#で小さな整数を使った簡易実装を作成した。

このコードは学習用であり、実際の暗号用途では使用しない。

## RSAの基本

RSAでは、まず2つの素数 `p` と `q` を用意する。

```text
p = 11
q = 5
```

この2つを掛け合わせて `n` を求める。

```text
n = p * q
n = 55
```

`n` は公開鍵と秘密鍵の両方で使用する。

RSAでは、`n` から元の `p` と `q` を求める素因数分解が非常に困難であることを利用している。

---

## φ(n)

RSAでは、オイラーのφ関数を使用する。

`p` と `q` が素数の場合、次の式で求められる。

```text
φ(n) = (p - 1) * (q - 1)
```

今回の場合、

```text
φ(55)
= (11 - 1) * (5 - 1)
= 10 * 4
= 40
```

となる。

φ(n)は、

> 1以上n未満の整数のうち、nと互いに素な整数の個数

を表している。

---

## 互いに素

2つの整数について、共通する約数が `1` しか存在しない場合、その2数は「互いに素」という。

例えば、

```text
9 と 40
```

の場合、

```text
gcd(9, 40) = 1
```

なので互いに素である。

一方、

```text
10 と 40
```

の場合、

```text
gcd(10, 40) = 10
```

なので互いに素ではない。

`gcd` は最大公約数を意味する。

---

## 公開指数 e

RSAでは、

```text
1 < e < φ(n)
```

かつ、

```text
gcd(e, φ(n)) = 1
```

を満たす整数 `e` を選ぶ。

今回の `φ(n) = 40` では、小さい数から調べると、

```text
e = 2
gcd(2, 40) = 2
NG

e = 3
gcd(3, 40) = 1
OK
```

となるため、

```text
e = 3
```

を採用した。

実際のRSAでは、`65537` が公開指数としてよく使われる。

---

## 秘密指数 d

秘密指数 `d` は、次の条件を満たす値として求める。

```text
e * d ≡ 1 (mod φ(n))
```

これは、

```text
(e * d) % φ(n) == 1
```

という意味である。

今回の場合、

```text
e = 3
φ(n) = 40
```

なので、

```text
3 * d % 40 == 1
```

となる `d` を探す。

```text
3 * 27 = 81
81 % 40 = 1
```

したがって、

```text
d = 27
```

となる。

---

## 公開鍵と秘密鍵

今回生成された鍵は次の通り。

```text
公開鍵
n = 55
e = 3
```

```text
秘密鍵
n = 55
d = 27
```

概念上、公開鍵は `(n, e)`、秘密鍵は `(n, d)` と表せる。

実際のRSA秘密鍵では、高速化などのために `p` や `q` などの追加情報も保持する場合がある。

---

## メッセージ m

暗号化したい元の数値を `m` とする。

`m` は、

```text
0 <= m < n
```

である必要がある。

今回 `n = 55` なので、

```text
0 ～ 54
```

の整数をメッセージとして使用できる。

---

## 暗号化

暗号化では次の計算を行う。

```text
c = m^e mod n
```

`c` は暗号文を表す。

例えば、

```text
m = 7
e = 3
n = 55
```

なら、

```text
7^3 = 343
343 % 55 = 13
```

なので、

```text
c = 13
```

となる。

---

## 復号

復号では次の計算を行う。

```text
m = c^d mod n
```

今回の場合、

```text
c = 13
d = 27
n = 55
```

なので、

```text
13^27 mod 55
```

を計算すると、

```text
7
```

になり、元のメッセージを復元できる。

---

## 累乗剰余

`13^27` のような値をそのまま計算すると非常に巨大になる。

実際のRSAでは指数や数値がさらに巨大なため、そのまま累乗すると現実的ではない。

そのため、計算途中で毎回 `mod n` を取る。

例えば、

```text
ans = ans * a % n
```

のように計算する。

これは、

```text
(a * b) mod n
```

と、

```text
((a mod n) * (b mod n)) mod n
```

が同じ結果になる性質を利用している。

これによって、途中の数値が必要以上に巨大になることを防げる。

---

## 今回実装した処理

今回の学習用プログラムでは、次の順番でRSAの処理を実装した。

```text
1. 素数 p, q を指定
2. n = p * q を計算
3. φ(n) = (p - 1) * (q - 1) を計算
4. φ(n) と互いに素な e を探す
5. (e * d) % φ(n) == 1 となる d を探す
6. 公開鍵 (n, e) を作成
7. 秘密鍵 (n, d) を作成
8. m^e mod n で暗号化
9. c^d mod n で復号
```

## 現時点での理解

RSAの基本的な考え方は、

> 2つの巨大な素数の積 `n` は公開してもよいが、そこから元の素数 `p` と `q` を求めることは非常に困難である

という性質を利用している。

`p` と `q` を知っていれば `φ(n)` を簡単に計算でき、そこから秘密指数 `d` を作ることができる。

一方、公開される `n` と `e` だけから秘密鍵 `d` を求めることは、巨大なRSA鍵では非常に困難になる。

今回の実装では小さな整数と `int` を使用しているが、実際のRSAでは2048ビット以上の巨大整数が使われる。

また、今回の実装では `e` や `d` を単純な総当たりで求め、累乗剰余も単純な繰り返しで計算している。

実用RSAでは、より高速なアルゴリズムや安全なパディング方式などが必要になる。
